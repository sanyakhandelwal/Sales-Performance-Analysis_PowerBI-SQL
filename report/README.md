# Report

This folder contains the Power BI report developed for the Retail Sales Analysis project.

## File

- **RetailSalesAnalysis.pbix** – The main Power BI Desktop report containing the data model, DAX measures, interactive visualizations, and business insights.

### Report Features

- Executive KPI Dashboard
- Month-over-Month (MoM) & Quarter-over-Quarter (QoQ) Analysis
- Revenue & Gross Profit Analysis
- Country and Town Performance
- Category & Price Range Analysis
- Sales Representative Performance
- Interactive slicers and drill-down capabilities
