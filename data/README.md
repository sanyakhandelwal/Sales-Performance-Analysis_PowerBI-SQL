# Data

This directory contains the raw datasets used for the Retail Sales Analysis project.

The dataset covers **Fiscal Years 2014–2017** and includes both fact and dimension tables used to build the Power BI data model.

## Folder Structure

- **sales/** – Sales transaction data for 2014–2017
- **Categories.xlsx** – Product category information
- **SubCategories.xlsx** – Product subcategory information
- **Product.csv** – Product master data
- **Geography.xlsx** – Country and town information
- **SalesRep.xlsx** – Sales representative details

These datasets were imported into Power BI to build a star schema, create DAX measures, and develop interactive business intelligence dashboards.
